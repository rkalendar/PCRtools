Universal PCR (uPCR) — Consensus Primer Design

Universal/consensus PCR primers from a multiple sequence alignment.

Read Instructions Troubleshooting

The tool performs a multiple sequence alignment, derives a per-column conservation profile, and designs universal primers anchored on conserved regions.

Every primer's 3′-end is guaranteed conserved across all sequences. The 5′-end may sit on variable columns (rendered as IUPAC-degenerate bases) when “Allow degenerate 5′-end” is enabled; otherwise primers are fully conserved.

Upload local FASTA file — plain FASTA or multi-FASTA, ≥2 DNA sequences

How it works. Coordinates in the output are 1-based alignment columns. A primer is reported only when its 3′-anchor window is 100% conserved across every input sequence. Product size is reported as the range of ungapped amplicon lengths over all templates.
