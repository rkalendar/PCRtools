STR / SSR — Microsatellite Fragment-Analysis Primer Design

Design flanking PCR primers for microsatellite genotyping by capillary-electrophoresis fragment sizing, with economical universal tail fluorescent labelling and automatic multiplex dye/size assignment for forensics, parentage and plant/animal markers.

Read Instructions

A microsatellite (STR / SSR) is a tandem repeat of a short motif (typically 2–6 nt — di- to hexanucleotide) whose copy number varies between alleles. Amplifying across the repeat with flanking primers turns each allele into a PCR product of a distinct length, sized on a capillary-electrophoresis instrument against an internal size standard.

Paste sequences (each containing one repeat — mark it with [..] or let the tool auto-detect it; TotalRepeats finds them genome-wide). The tool designs up to three Tm-matched, dimer-checked alternative primer pairs in the unique flanks, prepends a universal forward tail and a reverse PIG-tail — clear a field to omit it — and assembles a multiplex panel, assigning each locus a dye channel (and, if needed, a different alternative pair) so product sizes stay a minimum gap apart within any one colour.

Upload local FASTA file — each record should contain one microsatellite; mark it with [..] or rely on auto-detection
One labelled primer, many loci: every forward primer carries the same M13 tail, so a single dye-labelled universal primer per colour labels the whole panel — markers are spread across dye channels and size windows for co-loading on one CE run.

Different dyes may share a size range freely — colour tells them apart. Set Dye channels to 1 for a single-colour panel: every product is then separated purely by size, kept at least Min size gap apart (10–20 nt is typical for reliable CE resolution); the panel tries each locus's alternative primer pairs to make that fit.

The tail (e.g. M13) enables cheap fluorescent labelling (one dye-labelled universal primer per colour); the reverse PIG-tail (GTTTCTT) promotes full +A adenylation for sharper peaks. Both 5′-tails are templated into the amplicon, so the M13 tail (+18 nt) and PIG-tail (+7 nt) are already included in the reported product and allele sizes. For >1 dye, give each channel its own universal tail.

Need details? Repeat detection, parameters, the M13/Schuelke method and multiplex binning are documented in Help: STR/SSR workflow · Help: Troubleshooting
