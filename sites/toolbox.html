Browser-based tools for PCR design, genotyping, LAMP, sequence analysis and lab calculations.

Design & Assays
PCR, Multiplex & QF-PCR Design

Standard, inverse, multiplex, TaqMan, MGB-probe, bisulfite PCR and RPA assay design.

Universal PCR (uPCR) from MSA

Consensus PCR primers from a multiple alignment of ≥2 sequences with conserved 3′-ends.

Open tool →
Multiplex Tiling PCR Panel

Custom amplicon panel for NGS and TGS targeted sequencing across organisms.

Open tool →
KASP Genotyping Assay

AS-PCR / KASP / PACE / ASQ genotyping for SNPs, InDels and haplotypes, read by fluorescence or, in the allele-sizing mode, by band length on a gel.

Open tool →
SNP/InDel genotyping by qPCR with dual-labelled probes

TaqMan, MGB, Molecular Beacon and UniQ probe design for SNP and InDel genotyping assays, with multiplex mode for running multiple targets in one reaction.

Open tool →
castPCR Competitive Allele-Specific TaqMan PCR

Rare somatic mutation detection at 0.1% allele frequency. ASP + common TaqMan/MGB probe + common primer triplet design, with multiplex mode for running multiple targets in one reaction.

Open tool →
SNaPshot Multiplex SNP Genotyping

Single-base extension (SBE) primer design for multiplex SNP/InDel genotyping, BAC fingerprinting and methylation analysis on capillary electrophoresis.

Open tool →
MLPA, digitalMLPA Multiplex Probe Design

Ligation-dependent half-probes (LPO + RPO) for copy-number (CNV), SNP and InDel detection read by capillary electrophoresis or, for up to 1000 targets, by NGS (digitalMLPA).

Open tool →
STR / SSR Microsatellite Fragment Analysis

Flanking primers for microsatellite fragment analysis with universal tail labelling and multiplex dye/size assignment for capillary electrophoresis.

Open tool →
LAMP Primer Design

Isothermal amplification using 4–6 primers recognizing 6–8 distinct target regions.

Open tool →
CRISPR Guide RNA Design

Cas9/Cas12a guides with off-target scanning over your own sequences, HDR/ssODN donors with silent PAM protection, screening primers, prime-editing pegRNAs and base-editing windows with bystander prediction.

Open tool →
CRISPR Diagnostics (SHERLOCK / DETECTR)

crRNA, RPA pre-amplification primers and the collateral reporter for Cas12a/Cas13a detection, with allele-specific synthetic-mismatch crRNAs for genotyping.

Open tool →
Insertion & Knock-in Genotyping

Knock-in and empty-site assays for an engineered locus, designed as a pair so zygosity reads out on one plate, with the finished oligos checked in silico against both alleles.

Open tool →
loxP / FRT Assays

Recombinase sites and the hairpins they form, which pairs Cre or Flp can use and whether they excise or invert, and tear-pin and break-hairpin oligos anchored on each site.

Open tool →
PCA Gene Assembly

Polymerase cycling assembly: the overlapping oligo set that builds a gene from scratch, with junctions placed for an even overlap Tm, end primers, a cycling program and block splitting for long constructs.

Open tool →
Gibson Assembly Design

Seamless isothermal assembly of multiple overlapping DNA fragments in a single reaction.

Open tool →
TSDR Probes

Toehold exchange probe designer for high-specificity SNP/allele discrimination: near-thermoneutral ΔG°rxn tuning, measured mismatch NN thermodynamics, and predicted discrimination factor.

Open tool →
Gator GeneSwift Probe Design

Fluorescein / biotin probe pairs for AAV titer by biolayer interferometry (BLI).

Open tool →
In Silico PCR (ePCR)

Virtual PCR for primers, probes, miRNA or gRNA binding prediction and off-target detection.

Open tool →
Oligo Analysis
PrimerAnalyser

Single-oligo analysis: Tm, GC%, MW, extinction coefficient, OD, complexity, self-dimers.

Open tool →
PrimersList

Batch analysis of multiple primers: Tm, GC%, complexity, MW, self-dimers and cross-dimers.

Open tool →
RNA & DNA Secondary Structure

Minimum-free-energy folding of one sequence or two: hairpins, bulges, interior and multi loops, suboptimal structures, and hybridisation or co-folding of a pair. Full Turner nearest-neighbour model at any temperature.

Open tool →
Repeats & Genome
TotalRepeats

De novo identification, masking and clustering of repeats at genomic scale. Detects SSRs and interspersed repeats.

Open tool →
MUSCLE-JS Multiple Sequence Alignment

Needleman-Wunsch, Smith-Waterman and progressive MSA — all in the browser.

Open tool →
Phylogenetic Tree Builder

Neighbour-joining or UPGMA trees from an alignment, with corrected distances and bootstrap support — editable on screen and exportable as SVG, PNG, Newick or NEXUS.

Open tool →
CAP-JS Sequence Assembly

Assembles short, repeated or imperfect fragments into consensus contigs (CAP3-style overlap–layout–consensus), calls polymorphic columns as IUPAC codes, and runs the pairwise stage across Web Workers.

Open tool →
Sequence Utilities & Format Converter

DNA text transforms (reverse complement, case, bisulfite, clustering) plus file-format conversion between FASTA, FASTQ, GenBank, EMBL, Clustal, PHYLIP, NEXUS and GFF3, feature and CDS extraction with translation, and FASTQ read quality control.

Open tool →

Calculate reagent volumes for PCR, qPCR and LAMP. Supports 10+ polymerase presets.

Mix two solutions — molar, %, pH or any unit. Provide 4 of 6 variables; the rest are computed.
