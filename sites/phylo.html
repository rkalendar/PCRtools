Phylogenetic Tree Builder

Align, infer a neighbour-joining or UPGMA tree with bootstrap support, edit it interactively, and export vector or text formats.

Read Instructions

Paste DNA or protein sequences in FASTA. Unaligned input is aligned first with the same MUSCLE-JS engine as the MSA tool; already-aligned input is used as given. A distance matrix is then corrected for multiple substitutions and turned into a tree by neighbour-joining or UPGMA, optionally with bootstrap support.

Distance-based inference (Saitou & Nei 1987; Felsenstein 1985 bootstrap). Everything runs in your browser — no sequence leaves the device.

FASTA — aligned or unaligned, DNA or protein — or a Newick string to load an existing tree.
